# ApexWeb Trader (Vercel Deployable)

A standalone Next.js & React cloud trading web application designed for direct one-click deployment on **Vercel**. 
No MetaTrader 5 desktop app required—log in directly via API token or session key and manage live simulated/API trades anywhere.

## Deployment Instructions (Vercel)
1. Push this folder to a new **GitHub repository**.
2. Go to [Vercel](https://vercel.com), click **Add New > Project**, and import your repository.
3. Vercel will automatically detect Next.js and build it. Click **Deploy**.
4. Access your live web app URL instantly from any browser or phone!
